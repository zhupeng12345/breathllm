# Breath5 轨道 A

**UCDDB｜60 秒因果窗、1 秒步长｜五分类｜轨道 A 整夜连续监测**

轨道 A 是论文主任务。当前实验先完成轨道 A。在任务完成或用户明确要求换实验之前，持续推进本任务，遇到负结果就诊断模型和迭代算法，禁止自行切换到固定报警分型、其他窗口、数据集或任务。轨道 B 是辅助验证，使用固定检测器的报警和截至关闭时可见的信号，关闭后输出四种异常亚型，主指标为分型 Event F1。轨道 B 的唯一检测器留到启动该轨道前锁定。

## 固定设置

- UCDDB 共 25 人。日常开发固定用 `breath5/experiments/paper_eval/nested_split.csv` 中外折 1 的三个内折，20 人轮流验证，使用表中 `fit`、`select`、`reserved` 原名单。论文阶段在锁定模型后用同一清单做 25 人嵌套五折，属于同队列验证。独立数据验证另报。
- 四路 8 Hz PSG 为气流、胸带、腹带、SpO₂。整夜按 60 秒、每通道 480 点盲滑窗，步长 1 秒。五类顺序为 Normal、OSA、CSA、MSA、Hypopnea。未来预测 0 秒，每秒独立发布最新状态。模型的波形输入范围为当前因果窗。机制记忆按秒从历史输入累计并按夜重置。
- 冻结 OpenTSLM 主干，训练算法新增部分与适配读出。对输入内末 5 秒分别监督，每个位置仅看到截至自身的信号。训练按原始类别分布抽窗，使用有效标签，禁用类别或事件均衡采样及强制事件均衡权重。
- 固定种子 4121、4122、4123。只用内层验证做早停，默认主指标为有效睡眠逐秒 Macro-F1，同分取更早检查点。各组共用最大预算、检查频率和耐心步数，每阶段运行前一次登记，对比中途保持一致。外折标签仅用于最终评分。
- 轨道 A 独立输出五类概率。逐秒 Macro-F1 和检出 Event F1 为主指标，同时报告分型 Event F1 和逐类召回。沿用 Breath5 有效睡眠标签及阶段一整夜评分规则，异常总概率 ≥0.5，允许合并最多 5 秒间隔，至少 5 个阈值阳性秒。每夜一对一匹配，重叠至少为 5 秒和参考事件长度中的较小值。固定评分规则见 `breath5/src/score_runs.py`。

## 实验顺序

1. 先做数百个约 5–10 秒的快速候选筛选，分别探索 WD-AMT、MC-DPT、DT-EMM。把代理筛选与真实模型结果分别记录。
2. 接入冻结 OpenTSLM 验证候选。对 `v3wave` 原型先核对超出当前波形窗的显式参照输入和末五秒因果性。
3. 运行 Base、A、B、C、AB、AC、BC、ABC 八组消融，三折三种子整夜评估。所有组共用固定协议、训练预算和早停规则。
4. 锁定模型后做同队列嵌套五折及独立数据验证。

发布包使用 [实验协议](../../../docs/实验协议.md) 和 [当前研究任务](../../../docs/当前研究任务.md) 核对现行状态。T03 的无蒸馏版本继续锁定。历史结果在 [关键实验结果](../../../docs/关键实验结果.md) 按协议列出。
