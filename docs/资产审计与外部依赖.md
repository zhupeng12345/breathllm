## 归档字段与重建

T03 本地生成库的键是 `(version, experiment, fold, seed)`。每条保存训练超参、最佳步、拟合侧 mean/scale、角色、逐夜计数及来源哈希。快照含原始初始化及各验证检查步的适配参数。概率块保存训练和选择索引、每夜秒时钟以及五类概率。T03 本地入口每 128 步验证后原子保存优化器、RNG、适配权重和选位轨迹。中断后重复同一命令可以从匹配的检查点续跑。标签端点由原始数据和固定的开发清单重建，训练及选择索引由锁定随机种子重建。权重可用 T03 的训练和评分入口生成。历史原始输出依赖当时后端及原适配快照。选择历史本地库时逐条核对发布清单里的 SHA256。

R0 从这九条读训练覆盖、最佳步、夜间概率和计数。局部数值审计还需同源原始权重及波形。旧 P2 的零散归档以公开聚合摘要表示。R1 用原 A01 投影和训练配置，重新从同源 T03 生成冻结的 decoder 输入和原 logits，并逐夜复核缓存概率和归档概率。R1 的本地探针检查点独立保存。R2 复用 R0、R1 凭据与相同的九个 T03 归档。PAEL 的独立 FP32 生成路径以 R1 工程验收为前置。重复运行时按模型、数据、配置、索引及来源区分缓存。历史 T03-KD 或 B07 再拟合还需原 B01 教师，公开 T03 及 R 系列主链无需教师库。

## 发布验收

已执行 Python 语法与模块导入、README 全部入口帮助、合成概率和因果测试、20 种基线的无拟合接口检查、生产报警合成案例、缺失资产提示、划分和相对链接检查。独立目录用持有的官方数据字节重建 499,334 个开发窗并与旧标签清单切片的 SHA256 匹配。真实两窗 CUDA 短前向检查概率和、形状、因果性及历史初始化。使用授权本机资料，R0 的三折三种子只读复算及新目录的有限批次核验已执行。

完整 T03 重训、180 组基线及 R1/R3 全套拟合留作科研运行，交接验收使用只读和有限前向。原始权重、数据及历史预测通过 [README 安装和准备](../README.md#安装和检查) 在本机准备。
