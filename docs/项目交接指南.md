# 项目交接指南

**UCDDB｜60 秒因果窗、1 秒步长｜五分类｜轨道 A 整夜连续监测**

BreathLLM 研究如何从 PSG 连续识别睡眠期呼吸异常及亚型。OpenTSLM 把多通道信号转成时序词元，允许在同一模型中组织暂停程度和呼吸努力问题，再用任务读出处理逐秒监测。比较重点是自然睡眠分布下的报警和错分，XGBoost 等信号基线提供匹配对照。 [OpenTSLM 论文](https://proceedings.mlr.press/v306/langer26a.html) · [对照结果](关键实验结果.md)

| 类别 | 在项目中的含义 |
| --- | --- |
| Normal | 有效睡眠内无目标呼吸事件且标签明确 |
| OSA | 阻塞性暂停，呼吸气流停止或接近停止时仍有呼吸努力 |
| CSA | 中枢性暂停，暂停伴呼吸努力消失 |
| MSA | 混合性暂停，包含中枢性和阻塞性阶段 |
| Hypopnea | 呼吸减弱，项目将数据里的低通气亚型合并 |

医学术语依据 AASM 的规则说明，训练真值由 UCDDB 原标注按锁定映射生成。 [AASM 规则论文](https://doi.org/10.5664/jcsm.2172) · [数据来源](https://physionet.org/content/ucddb/1.0.0/)

轨道 A 是唯一当前主线，模型从因果窗独立输出五类并自主生成报警。轨道 B 使用固定检测器报警后只做四类异常分型。固定报警复算属于诊断，真实触发部署另需验证延迟和输入边界。

截至 2026-11-27，T03 锁定，T03-KD 九组已完成且未入选，20 种 Baseline 已完成。WD-AMT、MC-DPT v2、DT-EMM v2 已封存。R0、R1、R2 已完成，PAEL 六组 512 步完成且无晋级。当前科学问题是低通气的持续异常证据在匹配正常误报水平下能否改善，同时保住暂停检出和分型。外部验证应在独立可获得的多导 PSG 及逐事件标注中单列，输入模态和标签规则须先核对。

队友接手时先按 README 准备数据和权重并通过 smoke test。随后以相同的 T03/P00 锚点和评分器理解现有结果，再读瓶颈证据和研究状态。开发折用于候选判断。论文外层验证需在模型锁定且获授权后开展。
