# 历史创新与失败结论

三条路线使用 UCDDB 开发队列。各自的研究诊断和正式整夜成绩见 [关键实验结果](关键实验结果.md)。这里的结论限定于既有输入、模型和匹配对照。

## WD-AMT

原模块用因果参考幅值和分尺度气流／胸腹动态调制 OpenTSLM 词元。相对 log 幅值 (r)、log 能量 (e)、(e-2r)、归一化 AR(2) 残差共同作为窗口证据，残差可靠度为确定性变换。无截断及数值下限时，(e-2r) 消除统一幅值缩放，并可由 ((r,e)) 精确还原。原模块有 55 秒局部范围及末端绝对前缀。幅值与历史持续性也用匹配的冻结隐藏状态读出拆解过。

T03 上的原始模块九组复现显示种子依赖和误报取舍。简化幅值在独立探针中改善部分 CSA，同时 MSA 收益缺失。直接从 T03 加 (b) 残差的 P2 对照只多两例正确 CSA，来自同一受试者。轻度解冻和 LoRA 的匹配工程实验已归档，尚无持续推进 WD-AMT 的支持。 [核心数学与接入](../v3wave/代码/breathllm_m3.py) · [P2 聚合凭据](../config/历史汇总.json)

## MC-DPT

原设计把气流抑制与胸腹努力做条件关系组合，输出暂停亚型残差。胸带减气流、腹带减气流属于已有信号幅值的确定性重表达。条件乘积路线在 OSA/CSA 排序出现迹象，整夜分型增益不足。

v2 采用 20 秒去趋势和 Hann 窗，配对交叉谱在 0.1–0.5 Hz 内归一化聚合。复耦合系数为 `sum(X_i conj(X_j))/sqrt(sum(|X_i|²) sum(|X_j|²))`，输出实部、虚部及幅值派生量。门控使用折内能量中位数，按 `g_i=clip((E_i/(B_i+eps)-0.1)/0.2,0,1)`，交互按 (g_i g_j) 加权。同期关系没有超过幅值、时间错位和可靠性对照的预设收益门槛。胸腹极性在原记录中缺少统一确认。 [原关系实现](../v3wave/代码/breathllm_m3.py) · [v2 关键结果](关键实验结果.md#mc-dpt-v2)

## DT-EMM

原方案以中枢槽、阻塞槽和方向状态跟踪事件机制，含 (C\to O) 与 (O\to C)。旧版本跨整夜累计，被保留为扩展历史对照。严格 60 秒的有限历史重算版限制原始波形、参考和门控的支持；重算与增量记忆的等价性仍待验证。

v2 对连续气流抑制阶段加限制，比较同序、反序以及不同事件记忆读出，尝试捕捉由中枢低努力向阻塞努力恢复的变化。固定报警端到端的净正确数未改善，三种暂停混淆未稳定改变。当前开发 MSA 的两个主要贡献者合计占 80.47%，独立受试者覆盖是机制外推限制。 [原槽位机制](../v3wave/代码/breathllm_m3.py) · [v2 关键结果](关键实验结果.md#dt-emm-v2)
