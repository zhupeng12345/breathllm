**UCDDB｜60 秒因果窗、1 秒步长｜五分类｜轨道 A 整夜连续监测**

## 数据及监督

| 项目 | 黄金协议 |
| --- | --- |
| 数据 | UCDDB 1.0.0，正式标签版本 `breath5-sleep-midpoint-v1` |
| 划分 | 25 人完整嵌套五折表。开发固定外折 1、三个内折，拟合／验证分别 13/7、13/7、14/6 |
| 输入 | EDF 的 Flow、ribcage、abdo、SpO₂，8 Hz，`[B,4,480]` |
| 时间 | 60 秒历史，1 秒步长，半开区间，输出当前秒 |
| 标签 | 自动从 RESP 和分期重建。以秒中点落入标注为准，正常只含有效睡眠秒。含歧义或未分期位置为 `-1` |
| 监督 | 同一窗口末五个位置，每个位置只读取已出现的信号。批量标签为 `[B,5]` |

| 外层限制 | 日常指令只读取开发人的波形与标签。外折保留受试者只用于另行授权的最终验证 |

## 预算和选模

T03 每次最多 512 步、batch 32、AdamW 学习率 $2\times10^{-4}$，默认 betas 0.9/0.999、eps $10^{-8}$、weight decay 0.01，梯度范数上限 1。自然抽窗上限 16,384。内层固定 8,192 个有效末秒，选择种子 74121，按 Macro-F1 每 128 步核对，耐心 2，严格超过才换最佳权重。正式整夜成绩取锁定的最佳步。

R1 单折 128 步用于机制判断，固定结束步。PAEL 用同一训练索引的 4,096 窗作为 128 步中间点，最终按 512 步判断。原 Baseline 的神经网用共同预算，传统模型的配置和早停单位见参考文献映射。 [训练与模型](T03模型设计.md) · [基线设置](参考文献.md)

## 生产评分

异常总概率 $P_O+P_C+P_M+P_H\ge0.5$ 且秒标签有效时置阳性。允许合并最长 5 秒的间隔，报警至少含 5 个阳性秒。分型累加报警内部阳性秒的四类异常概率，最高者获类。参考事件按有效标签的连续同类区间生成。每夜一对一匹配，重叠至少为 $\min(5,\text{参考事件秒数})$，先最大化匹配数，再最大化重叠。

逐秒 Macro-F1 为五类各自 F1 等权，分型 P/R/F1 使用各类报警与真实事件数为分母。检出 Event F1 用 $2\,\text{匹配数}/(\text{报警数}+\text{真值数})$。分型 Event F1 的分子改为两倍正确分型匹配数。FA/h 为未匹配报警数除以有效睡眠小时。固定报警诊断保留原报警边界和匹配，只改分型读出。

多种子对照按受试者先平均种子计数，再合并计算。配对 Bootstrap 以受试者为单位重抽，跨开发折的配对可按内折分层，记录各实验重抽次数和种子。R1、R2 和 PAEL 的重抽次数为 10,000，种子 74121。 [生产评分器](../breath5/src/score_runs.py) · [事件计数及概率分解](../v3wave/代码/B07基座改造实验.py)
